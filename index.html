About Us

xyecocPROJECT is a modern OSINT tool with a graphical interface. It works without API keys, everything runs locally, and everything is free.

Features

  • IP Info — country, region, city, ISP, coordinates
  • DNS Lookup — A, AAAA, MX, NS, TXT, CNAME records
  • HTTP Headers — full site headers and server info
  • Domain Report — full HTML report saved to your desktop
  • Phone Report — carrier, region, country by number
  • Chat System — local chats, groups, user search

How to Install

1. Clone the repository

git clone https://github.com/tipmetro-bot/xyecocPROJECT.git
cd xyecocPROJECT

2. Install dependencies

pip install requests python-whois dnspython

3. Requirements

  • Python 3.8 or higher
  • tkinter (usually bundled with Python)
  • Windows / Linux / macOS

Linux — install tkinter

sudo apt install python3-tk

macOS — install tkinter

brew install python-tk

4. Run

python xyecoc.py

5. First launch

  • A login window opens
  • Click "No account? Register"
  • Fill in email, nickname, username, password
  • Accept the agreement
  • Start using the tool
